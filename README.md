# 🚀 Backend Control de Cursada - Data Analyst

API REST desarrollada en **Node.js** y **Express** para gestionar la asistencia a clases y el progreso de las materias de la carrera de Analista de Datos.

## 🛠️ Tecnologías Utilizadas
* **Entorno de ejecución:** Node.js
* **Framework:** Express.js
* **Base de Datos:** PostgreSQL (alojada en Clever Cloud)
* **Despliegue Backend:** Render

## 📌 Funcionalidades
* Conexión a base de datos relacional PostgreSQL.
* Endpoints para consultar y actualizar el estado de cada clase (`/api/estados`, `/api/guardar`).
* Configuración de CORS habilitada para consumo desde cliente web estático (Netlify).
